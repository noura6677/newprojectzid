# نجدية ☕ — متجر تجريبي مدعوم بـ «صانع الصفقات AI»

متجر **Demo Sandbox** فقط لعرض أداة SaaS باسم **صانع الصفقات (Deal Maker AI)**.

> ⚠️ ليس متجراً حقيقياً: لا دفع حقيقي، لا خصومات حقيقية، لا تجارة فعلية — كل شيء Simulation.

## المميزات المعروضة

- 🟡 **وضع المراقبة (Passive):** فقاعة خفيفة عند الدخول.
- 🟢 **وضع البيع (Active):** يُفعّل عند أول إضافة للسلة → نظام مستويات (مبتدئ/هاوي/خبير/محترف) + اقتراحات Cross-sell وBundles ديناميكية.
- 🎯 **طبقة التحفيز:** عند الدفع بمنتج واحد فقط → عجلة الروليت.
- 🎁 **مكافأة مقفلة + مؤقت:** تُفعّل عند إضافة منتج ثانٍ.

محرك السلوك يحلّل المنتجات تلقائياً ويستنتج المكمّلات (قهوة → أداة + كوب…).

## التشغيل

أي خادم ملفات ثابت، مثلاً:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

لا توجد تبعيات ولا خطوة بناء — HTML/CSS/JS فقط.
